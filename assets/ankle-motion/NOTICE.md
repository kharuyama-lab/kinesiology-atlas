# Derived ankle motion geometry

BodyParts3D - The Database Center for Life Science - CC-BY-SA 2.1 Japan

Z-Anatomy - The open source atlas of anatomy - CC-BY-SA 4.0

Source web GLBs: nqwrc / 3d-anatomy, pinned skeletal, joints and muscular
revisions/hashes in `../../config/model-assets.js`.

`normals.bin.gz` stores display normals for the same derived geometry.

`positions.bin.gz` stores modified ankle vertex trajectories for the educational
joint, muscle, ligament and retinaculum display. Changes include attachment
transport, whole-muscle excursion, exterior contact routing and interpolation
clearance. This derived geometry retains the original anatomy credits and
applicable license conditions; it is separate from the original application and
ATLASCEND branding reservation.
