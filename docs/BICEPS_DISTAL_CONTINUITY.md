# 長頭の停止側の折り返しと角度間の震え

2026-11-04。05dd0adで残った停止付近のヘアピン状変形と、動作中の小刻みな震えを修正する。

## 原因と変更

長頭の自由経路は最初の骨付着頂点の手前で終わり、その先のメッシュ全体を下腿と一緒に固定していた。このため停止側に下腿方向の折り返しが作られ、その上に層支持を重ねていた。長頭だけ自由経路を起始から停止端まで延長し、全長の短縮へ置き換える。長頭の元の中心経路から緩やかな偏位を残して断面を移送する。下腿方向への強制的な終端接線は除去する。固定するのは元メッシュから判定済みの実付着領域の頂点であり、遠位部分全体ではない。

層支持で使っていた4mm格子への丸めと近傍ビン切替は、角度を連続的に動かしても支持量を跳ばせる原因だった。固定したソース頂点の集合と、距離に対して連続なGaussian重みへ変更する。経路の支持は2回の全長補正で行い、短頭を内側へ押す処理や時間方向の遅延フィルタは使わない。同じ角度には履歴によらず同じ形状を返す。

短頭・他筋の走行式とUIは変更しない。既存Hipリポジトリ・公開サイトも変更しない。

## 検証

biceps-continuityは0/30/60/90/120°の静止形状を確認し、さらに実際のAuto再生を記録して、同じ実メッシュ頂点の位置差と角度あたりの差分速度の変化を測定する。Autoは1°以上進むごとに記録し、変位と速度変化は2°刻みに相当する値へ正規化する。長頭の局所方向変化<10°、余長比<1.06、段階的な短縮、2°あたりの頂点移動<4mm、2°刻みの差分速度変化<1.2mmを条件とする。実付着とホバーはcontinuous-muscles、長頭/短頭と内側筋の層はshort-head/terminal-muscle-layersで確認する。

長頭が短縮して短頭とY-Z投影上で重ならなくなると、従来のX方向だけの層検査では比較点が0になる。この場合も検証を空判定にせず、大腿骨局所の同じ長軸区間にある実表面を照合し、大腿骨中心からの径方向の表層包絡を比較する。全ての検査で必要サンプル数>10、逆転0、最小差>1.4mmを維持する。内側筋のX方向判定は変更しない。これは表層包絡の検査で、完全な三角形接触・張力の解析ではない。

表面参照・連続性検査の代表点は各筋全体で最大320点に固定する。パーツごとに320点を追加する方式にはせず、分割数に応じて計算量が増える問題を除いた。

## 最終結果

構文チェック・単体41件・ブラウザ4件（biceps-continuity、continuous-muscles、short-head、terminal-muscle-layers）が成功。Autoの57フレームを計測。2°相当に正規化した最大頂点移動は2.382mm、差分速度変化は0.426mm。120°の長頭中心経路の最大方向変化は2.05°、余長比は1.0008。詳細はbiceps-continuity-audit.json。
