# 十字靭帯の滑らかな表示表面（2026-11-02）

## 問題と変更

前後関係の補正で残った元メッシュの端部と、補正した中央部との間に、折れ・くびれ・局所的な波打ちが見えていた。面の細分化と平滑化だけでは輪郭の折れが残ったため、その方式は採用しない。

確認済みGLBのACL/PCLだけ、元の近位・遠位付着面中心と、元メッシュから推定した幅を使う滑らかな帯状の表示表面へ再構成した。33断面×20周方向分割、両端の閉じた面を持ち、断面幅と厚みを連続的に補間する。伸展位の中心線は両付着点を結び、途中のS字折れを作らない。屈曲・回旋時には断面の向きを滑らかに補間し、端面は各付着骨のフレームへ固定する。

元の付着中心の位置は移動しない。元の全表面頂点や、付着面の輪郭そのものを完全維持する変更ではない。表面と端面は教材表示用の近似形状であり、元GLBの変形だけによるものとは区別する。MCL/LCL、骨運動、軸、半月板、膝蓋骨、UI配置と初期値は変更しない。確認済みハッシュ以外のモデルや不正な非表面入力は変更しない。

## 検証

構文PASS、ロジック25/25 PASS、関連実GLB UI3/3 PASS。

- 伸展位の各断面中心が付着点間の直線上にあること、端面フレームの固定、断面積の保持、有限な全頂点、外向き閉表面をロジックで確認。
- 元GLBを独立して再読込し、生成した両端面の中心を元付着領域中心と照合。
- Anatomy、屈曲0/30/60/90/120°、内旋15°・外旋30°で中央交差部の前後関係を再確認。
- 5靭帯×11肢位の付着フレーム追従、ON/Fade/OFF、Mode保持、伸展・内旋時の発光を回帰確認。
- 骨OFFの伸展・屈曲拡大画像を保存：screenshots/cruciate-surface。前後関係のデータ：cruciate-surface-review.json。

## 範囲

滑らかな表面と表示の改善であり、束別の実形状・材料長・張力・骨面巻き付き・ACL/PCL相互接触の物理モデルではない。付着部の解剖学的最終検証済みを意味しない。
