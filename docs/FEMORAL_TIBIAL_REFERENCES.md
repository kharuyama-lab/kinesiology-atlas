# 大腿骨固定2軸と脛骨共通原点3軸（2026-11-02）

以前の青線は変換の微分から求める移動瞬間軸だった。今回の比較表示では不要なため、描画を削除した。運動式の診断用瞬間軸計算は変更していない。

- 大腿骨：骨幹長軸（緑破線）と顆部横方向を床面へ投影した固定横線（青破線）。両線を大腿骨座標に固定。脛骨の変換・瞬間軸の移動を適用しない。
- 脛骨：長軸方向を基準に、直交する横軸（青）・前後軸（橙）・上下軸（緑）を構成。すべて脛骨座標原点を通り、脛骨の同じ回転・並進に追従。
- 青実線と青破線の偏移で回旋を比較する。終末伸展の既存Screw-home曲線は変更・誇張していない。
- 角度表示は全3運動とも整数。運動計算とスライダー精度は保持。

検証：実GLBの大腿骨2線の両端を0°/90°で比較し固定を確認。脛骨3線の中点が一致。0°から20°で実描画の脛骨横線方向が7°超変わることを確認（既存約9°の軸回旋に対応）。全3運動の角度表示に小数点がないこと、Auto位置・往復・Mode保持、通常パネルの1280×800収まりを確認。長軸・顆部線はメッシュ由来の暫定ガイドで、FTAの校正済み計測ではない。

結果：構文PASS、関連UI4/4 PASS。

## 脛骨原点の修正
