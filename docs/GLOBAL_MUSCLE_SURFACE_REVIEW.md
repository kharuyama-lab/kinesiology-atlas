# 全筋同時表示・筋表面の再検証（未完了の解剖学的検証あり）

2026-11-02。9176297での「修正済み」という報告は不十分だった。筋中心線の検証と単独表示では、全筋表示時の埋没、薄筋・縫工筋の表面の交差、ハムストリングスの末端の折れを検出できていなかった。

## 今回変更したもの

- 内側筋群と大腿二頭筋を共通の全長経路に統一。大腿二頭筋にも、旧来の「膝近傍だけ曲げる」処理を使わない。
- 下腿に固定する範囲を、膝中心から一律に決める方式から、元メッシュが骨に接近する推定付着領域に変更。その領域は骨とともに動かし、接続側の接線を合わせる。
- 自由な筋部分は経路の弧長に沿って均等に再配置し、末端だけに短縮を集中させない。
- 内側の浅深拘束に元断面の幅を加味。薄筋と縫工筋では四頭筋の描画表面サンプルも参照する。局所の点を押し出す代わりに、全長に支持を持つ滑らかな変位を使う。ただし最大変位は制限しており、全表面の非交差を保証する最適接触解ではない。
- 腓腹筋の筋腹は下腿座標に保持。近位移行部の断面を屈曲時に絞り、骨への推定付着面は保持する。これは暫定的な形状調整で、計測で確定した解剖学的厚みではない。
- Mode 2の伸展位にも同じ全長経路を使う。Anatomyの静止原形、四頭筋の既存経路、UI、Hip操作、関節・靭帯の運動式は今回変更しない。
