# 靭帯の濃淡・発光と骨表示（2026-11-02）

最新修正：ONは緊張にかかわらず不透明、Fadeのみ30%。伸展時の強調とLCLのたわみ取りを追加。[修正・検証記録](LCL_REFINEMENT.md)。以下の初版仕様から透過による濃淡は廃止。

ユーザー指定の定性表示として、内旋時はACL/PCL、外旋時はMCL浅層・深層/LCLを強調。内外反もMCLは外反、LCLは内反で強調する。現在のスライダー端を教育用の最大強調として正規化し、実測張力・ひずみ・破断閾値として扱わない。回旋時のメッシュの走行変化は前回の付着部追従によるもので、ACL/PCL相互接触の物理解法は未実装。

参照したlegacy/hip/index.htmlの濃淡・発光式に合わせ、緊張の弱い状態は淡色、強い状態は元の識別色で不透明にする。最大側で発光が強まり、同じ低速正弦波の脈動を使う。靭帯を手動Fadeにした場合は不透明度30%を維持し、発光も弱める。OFFは表示しない。Anatomyでは動態の濃淡・発光を解除。選択時の強調と合成し、更新のたびにユーザーの表示状態を上書きしない。

骨の一括ON/Fade/OFFを既存表示ボタンと同じデザインで追加。Fadeは30%、OFFでも骨格ノードとリグを保持。膝蓋骨の個別設定と組み合わせ、骨一括OFFが優先する。Mode切替で保持し、Whole BodyホームではONへ復帰する。3ボタンを同じ行に収め、Auto/Reset poseの配置を維持。

検証：構文PASS、ロジック23/23 PASS、関連UI5/5 PASS。内外旋端で対象靭帯の不透明度・発光と非対象の淡色、明示Fade/OFF、骨表示循環・Mode保持・Whole Body復帰、軸と膝蓋骨/半月板の回帰、1280×800のパネル超過0pxを確認。

参考：[OpenSim膝モデル研究](https://link.springer.com/article/10.1186/s12938-018-0474-8) は複数束や材料設定を備えた研究であり、本画面の定性スコアはその張力・ひずみ計算の再現ではない。Hipの原本ファイルと既存のhip-kinesiologyリポジトリ・公開サイトは変更していない。
