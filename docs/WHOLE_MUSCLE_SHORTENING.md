# 全長での筋短縮と浅深関係の修正

2026-11-02。前回の局所経路修正では、薄筋などに大きなV字状のたるみが残った。骨への付着位置が一致していても、筋全体の形状が妥当とは限らなかったため、今回の確認対象を広げた。

## 変更

- 薄筋・縫工筋・半腱様筋・半膜様筋の屈曲時追従を、起始から停止側まで一続きの滑らかな短縮経路へ変更。筋腹だけを残して停止近傍を折り曲げる処理を廃止した。
- 下腿側の継続部へは接線方向を合わせる。元の断面を経路に沿って回転させ、過剰な全長のたるみを抑える。筋腹の肥厚は今回追加していない。
- 縫工筋は内側筋群と交差する範囲で浅層側に経路を確保。元の骨付着点は移動しない。
- 膝窩筋も全体の経路で追従させ、同じ描画フレームのLCLメッシュを参照して交差近傍を深層側へ補正。LCLの付着点・既存運動式は変更しない。
- 改善済みの腓腹筋と四頭筋の経路式、大腿二頭筋、UI、Hipの既存経路式は保持した。Static Anatomyは元のGLB形状を保持。

## 検証

構文チェックと単体テスト39件成功。実GLBで0/30/60/90/120°の筋走行・ホバーを確認。骨に対する筋腹・停止部、四頭筋の骨内への沈み込みの検証も成功した。Auto（2件）とHip/Knee共有・切替の回帰確認も成功。

新しい `whole-muscle-shortening` テストは、自由な筋部分の経路長／両端距離、隣り合う経路区間の向きの変化、LCL交差近傍の浅深関係を記録する。4筋すべてで120°時の経路全長が0°時より短くなることを確認した。下腿に沿う腱の継続部まで含めた全長比率と、自由な筋部分の比率を区別した。最大屈曲では自由部分の比率が約1.01〜1.04、64区間で計測した最大の方向変化は約15〜17°。これは局所的な折れ・過剰なたるみの回帰検出値で、生理学的な基準値ではない。

LCLが膝窩筋腱より浅層を通る関係の参照：[解剖学的後外側支持機構再建の原著手技](https://pmc.ncbi.nlm.nih.gov/articles/PMC7917225/)。描画を重ねる順序ではなく、3D形状の深さを補正している。
