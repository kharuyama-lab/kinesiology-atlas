# 軸と表示UI整理（2026-11-02）

- 大腿骨：骨幹部32%/68%付近の頂点帯の中心を結ぶ長軸を推定し、大腿骨座標に固定（緑破線）。脛骨回転・並進を与えない。
- 脛骨：同じ方法の骨幹長軸（緑実線）と前後軸（橙）だけを脛骨へ追従。画面垂直の線、回旋0の前後破線を削除。
- 左右の瞬間屈伸軸（青）は維持。FTA測定値は表示せず、骨幹長軸は暫定推定として扱う。
- Axesと膝蓋骨を同じ2列・同じ形の表示ボタンへ統一。AxesはON/OFF、膝蓋骨はON/Fade/OFF。AutoはReset poseの左を維持。
- 屈伸を屈曲・伸展へ修正。運動ボタンは日本語／英語を各1行に揃え、語中折り返しを防ぐ。

実GLBテスト：大腿骨長軸の両端が屈曲前後で固定、脛骨長軸と前後軸が動くことを座標で確認。全3運動で表示、表示ボタンの同一行・同じ高さ、Auto位置・往復とMode保持、膝蓋骨表示・半月板回帰、1280×800のパネル収まりを検証。骨・組織の運動式は変更なし。

結果：構文PASS。関連UI6ケースPASS（新規軸1・再生2・通常表示1・膝蓋骨/半月板2）。通常表示の超過18pxを余白調整で修正し再実行PASS。
