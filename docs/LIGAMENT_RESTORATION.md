# 元の付着設定へ復帰・伸展時のみ強調（2026-11-02）

ユーザー指示により、MCL近位代表点の暫定移動、基準長に合わせた曲線経路生成、緊張スコアによるLCL直線化を撤回。ligament-follow.jsは追従初版d055361とバイト一致する状態へ戻した。元GLBを基準とする両端領域の位置を保ち、大腿骨／脛骨・腓骨に追従する。

元GLBが解剖学的に独立検証済みという意味ではない。付着面は注釈付きの検証データではなく、元メッシュ端領域からの設定。今回の変更で付着部を移動させない。

色・発光は伸展側のACL/MCL/LCLだけに限定。0〜30°の間で弱まり、それ以上では発光しない。回旋・内外反・屈曲側のPCL強調を除去。形状の長さを色のスコアへ合わせる操作はしない。ON不透明・Fade30%・OFF、骨一括表示、軸、Auto、半月板、骨運動の設定は維持する。

検証：構文PASS、ロジック23/23 PASS、関連UI2/2 PASS。元追従実装とのバイト一致、5靭帯×11肢位の付着部追従、伸展の発光、90°で内旋/外旋しても発光しないこと、ON/Fade/OFF、Mode保持、1280×800のパネル収まりを確認。画像はscreenshots/ligament-restoration。
