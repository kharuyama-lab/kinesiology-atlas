## 実装済み
- Mode 1: Z-Anatomy系GLBから全身骨格を読み込む。右膝・右股関節へのフォーカス、前後・右外・右内側の視点、右膝のACL/PCL/MCL/LCL・内外側半月板を静止観察。
- Mode 2: 90°股屈曲を基準とする膝屈伸（0–140°）、90°膝屈曲位での内外旋（内旋15°／外旋30°）、30°膝屈曲位の微小内外反（±3°）。終末伸展に連動する試作スクリューホーム、下腿軸ON/OFF。
- 組織をタップ／クリックすると日英名称と表示状態を直接変更できる。

2. 全身骨格と右膝を表示し、右外側＝身体右側が正しいことを確認。
