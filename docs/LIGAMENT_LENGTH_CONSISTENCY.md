# 靭帯の経路長と緊張表現の整合性（2026-11-02）

## 実際に見つかった矛盾

従来の追従形状は角度別の端点補間で変形し、LCLの直線化は緊張スコアで別途操作していた。そのため、短い骨間距離なのに描画経路が伸びたり、強調すると経路そのものが縮んだりする構成だった。

加えて、元メッシュ端領域の平均を使うMCLの付着点では、90°で端点距離が浅層+5.4%、深層+4.9%となっていた。発光の調整だけで授業図と一致させるべきではない。

## 変更

- 緊張スコアでLCLを直線に縮める処理を撤回。代表経路は伸展位の基準長と現在の端点距離から計算する。
- 端点距離が基準長より短い場合、代表経路の長さを変えずに曲率を増す。長い場合には経路長が端点距離以上になる。色スコアは経路長計算に使わない。
- MCLの代表近位付着点を、元メッシュ近位付着領域内の近位・後方点へ暫定校正。骨運動・軸には変更しない。浅層約4.84mm、深層約3.96mmの代表点変更で、付着カラーも対応する骨座標へ補正する。解剖学的に確定した付着面ではない。
- MCL/LCLの発光上限は端点距離の短縮による余長にも依存させ、角度が端にあるだけで最大発光にしない。8%の短縮幅を表示調整の暫定尺度とし、実測張力への換算はしない。
- ON=不透明、Fade=30%、OFF=非表示を保持。

## 数値比較

0°を1とする90°の代表付着部間距離：ACL 0.844、LCL 0.878。校正後MCLは浅層0.959、深層0.973（従来は1.054、1.049）。これら4構造は0/30/60/90/120°で代表経路長を基準長に保ち、端点が近づいた分を曲率へ振り替える。PCLは屈曲角による走行長変化を別扱いし、一律に短縮させない。

## 検証と限界

構文PASS、ロジック25/25 PASS、関連UI4/4 PASS。経路端点の一致、基準長の保持、基準長を超える端点間距離への対応、5靭帯の骨追従、ON/Fade/OFF、同じ内側視点の比較を確認。比較数値はligament-path-consistency.json、画像はscreenshots/length-consistency。

これは代表経路の数値的一貫性と、元付着領域内での暫定校正である。個々の表面線維全ての材料長、骨面への接触・巻き付き、ACL/PCL相互接触、束別の無負荷長・張力は未検証。顆部の近似球には既存付着点が内側に入るため、球面巻き付き式をそのまま使うことも避けた。授業用の解剖学的な最終承認には、付着面と走行の確認を要する。

## 参照

ユーザー提供スライドを定性表の基準にした。[ACL/PCLの生体内長さ変化研究](https://pubmed.ncbi.nlm.nih.gov/15310565/)と、[側副靭帯の線維別研究](https://pubmed.ncbi.nlm.nih.gov/16411288/)も参照し、単一の平均長を全束の緊張度として扱わない。
