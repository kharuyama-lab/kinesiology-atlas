# 筋全長の連続変形と変形後のホバー判定 — 2026-11-02

## 前回の検証で不足していた点

筋腹の中央が骨と同じように動くことは、起始・停止へつながる部分の健全性を示しませんでした。前回の部分回転・短い移行域では、中央の剛体追従を満たしても起始付近にヘアピンが残り、腓腹筋の移行部に局所的な折れが生じていました。旧 `muscle-belly-frame-audit.json` はこの旧方式の中央域だけを検査した履歴で、今回の方式の妥当性を示すものではありません。

## 今回の変更

- 大腿二頭筋の両頭、半腱様筋、半膜様筋、縫工筋、薄筋、腓腹筋の両頭、大腿直筋に、名称ごとに共通の連続した筋経路を導入しました。離れた股・膝中心から頂点ごとに部分回転する方式を使いません。
- 起始と停止の位置を骨変換から求め、途中は滑らかな3次曲線でつなぎます。両端を結ぶ方向に逆行しないよう中間制御点を制約。各部分の向きも全長で連続的に変化させます。
- 元メッシュの断面形状をこの経路に沿わせます。長さの変化に伴う太さの変化も全長の筋腹へ滑らかに配分します。描画用の有界な変形であり、筋力や定量的な収縮率・体積保存を解いたものではありません。
- 広い骨面に起始を持つ広筋・膝窩筋、大腰筋の腰椎側固定域、腸脛靭帯/TFL/大殿筋の既存処理は、この二端型の経路に置き換えません。骨格・関節運動・半月板・靭帯の形状計算は変更しません。
- ホバー欠落の原因の一つは、変形後に包囲球だけを更新して、当たり判定が使う包囲箱を更新していなかったことでした。筋・靭帯・半月板の変形後に双方を更新します。
- Anatomyでは保存していた元座標へ戻ります。元GLBファイル・頂点数・接続情報は変更しません。既存Hipリポジトリと公開サイトも変更しません。
