# 骨に対する筋走行の修正 — 2026-11-02

屈曲時に筋腹・停止部が骨から離れる問題を、筋ごとの骨座標と局所経路で修正した。Static Anatomyと既存Hipの経路は保持し、Kneeの運動中に適用する。

- 腓腹筋：筋腹は元GLBの下腿後面の位置を脛骨とともに追従する。近位部のみ大腿骨付着側へ局所断面を補間し、離れた関節中心周りの補間による飛び出しを抑える。アキレス腱は既存下腿側追従を継続。
- 大腿四頭筋：大腿骨側から膝蓋骨側へ移行する経路と、その先の脛骨側継続部を区別した。同名の筋腹・腱部は共通の移行範囲を使う。元の大腿骨メッシュから採った皮質外包絡面で、遠位部の骨内への沈み込みを抑える。
- 縫工筋・薄筋・内側ハムストリングス：改善済みの起始側経路を保持し、膝近傍だけを短縮した局所経路へ移行する。停止側は脛骨に追従し、内側大腿骨の外側に経路を保つ。
- 大腿二頭筋：既存の大腿部経路を保持し、停止部近傍だけ腓骨側へ追従させる。
- Mode 2の伸展位でも骨への追従を保ち、Anatomyへは既存の肢位補間とともに戻す。UIの筋作用グループ名・配置、Hip操作、関節・靭帯の運動式は今回変更していない。

## 検証

- 構文チェック成功。単体テスト39件成功。
- 実GLBの屈曲0/30/60/90/120°、内外旋、内外反で検証。表示頂点を、実際に描画するFemur/Tibia/Fibulaメッシュの現在行列と保存した元行列から得た位置と照合した。
- 腓腹筋の筋腹位置、推定付着部、遠位部追従、維持すべき大腿部経路の誤差を0.1mm未満で確認。四頭筋のサンプル対象点が大腿骨包絡面の内側に入らないことも確認した。
- 実GLBテスト `bone-muscle-routes`、16組織のホバーと筋走行テスト `continuous-muscles` が最新変更後に成功。Auto、モード共有、角度表示の回帰確認は別途実施。
- [実測データ](bone-muscle-route-audit.json)、[ホバー・筋走行データ](continuous-muscle-audit.json)、[画像](screenshots/bone-muscle-routes/)を保存。最大屈曲の内側・外側画像を目視確認した。

`routes`が今回描画した骨に対する検証値。`referenceCurves`はHipおよび従来経路の参照値で、今回のKnee表示を直接検証する値ではない。

## 適用範囲

付着領域は元GLBと骨への距離から推定しており、解剖学的に確定した付着面ではない。皮質包絡面はサンプルによる近似で、筋同士の全接触・衝突や力、定量的生理学を解くものではない。最大短縮時の輪郭や筋同士の重なりは引き続き目視評価が必要。

[OpenSim Muscle Editor](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090145/Muscle%20Editor)のvia point・moving point・wrappingによる筋経路の考え方を参考にした。OpenSimの計算を実行した結果ではない。

追加回帰確認：angle-stability、playback（2件）、shared-musclesの計4件成功。
