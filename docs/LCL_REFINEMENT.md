# LCL・伸展時の緊張とON表示修正（2026-11-02）

## 修正

- ONは常に不透明度1、Fadeのみ0.3、OFFは非表示。緊張の弱い状態を透過で表す処理を廃止し、識別色の淡色化と発光だけで濃淡を表す。
- 教育用の定性スコアに屈曲角を加え、伸展0〜30°でACL/MCL/LCLの強調が滑らかに変わる。PCLは屈曲45〜120°側の強調として分ける。内旋のACL/PCL、外旋のMCL/LCL、内外反の強調は維持。これらの角度・強度は生体張力の校正値ではない。
- LCLは緊張スコアに合わせて中間部を両端間の直線的な走行へ近づける。近隣断面の中心から横方向の厚みを保持し、単なる頂点列への潰し込みを避ける。両端カラーは従来の剛体追従を保持し、付着位置を動かさない。Anatomyへ戻すとこの教育用のたわみ取りを解除する。

## 検証

構文PASS、ロジック24/24 PASS、関連UI3/3 PASS。合成のたわみ形状で、緊張時に中央のたわみが減り、両端が保持され、弛緩へ戻すと元形状に戻ることを確認。実GLBの5靭帯×11肢位の付着部追従を再確認。ON全靭帯の不透明、手動Fade/OFF、伸展時のACL/MCL/LCL強調、PCLとの区別、LCLの90°弛緩・外旋時のたわみ取りを画面で検証。

## 根拠と限界

[LCLの解剖・運動学研究](https://pubmed.ncbi.nlm.nih.gov/11101111/)では、屈曲に伴う付着部間距離の短縮を報告。[側副靭帯の線維別研究](https://pubmed.ncbi.nlm.nih.gov/16411288/)では、部位によって長さ変化が一様でないことを示している。今回の表示は指定された授業用の定性表現であり、束別の実測張力・ひずみ、接触・巻き付き・破断の計算ではない。骨運動・半月板・軸・UI配置は変更しない。
