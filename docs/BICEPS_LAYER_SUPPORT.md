# 大腿二頭筋の表層・深層と長頭の全長変形

2026-11-04。54d5f40で残っていた、屈曲時に長頭が大腿骨側に寄り短頭が表層へ現れる問題を修正する。今回の指摘に従い、長頭も修正対象とする。

## 変更

- 長頭の自由経路を、起始・停止だけで作る曲線から、元の筋経路へ両端の変位を全長で分配する形へ変更。遠位側の方向変化も広い区間に分配する。
- 短頭の実メッシュ表面を大腿骨の局所座標で取得し、重なり領域で長頭を表層に保つ支持を算出する。長頭の断面全体を滑らかな全長関数で移動し、起始・停止の端点は固定する。短頭を内側へ押し込む補正は再導入しない。
- 支持後に断面の向きを再計算し、反復して表面の逆転を抑える。材質・描画順序・表示状態による隠蔽は行わない。
- 他の筋の走行式、UI、既存Hipリポジトリ・公開サイトは変更しない。

## 検証の更新理由

以前のapproved-biceps-long.jsonは、今回不適切と指摘された長頭の走行を固定する基準だった。この基準ファイルは履歴として保持するが、長頭不変の条件は今回の明示的な修正依頼で置き換わる。新しい判定は、長頭の段階的な短縮・自由経路余長比<1.15・方向変化<25°・長頭表層/短頭深層の表面順序である。従来の表面順序のサンプル数>10、逆転0、隙間>1.4mmは維持する。描画の収束を待って計測する。

short-headは0/30/60/90/120°、terminal-muscle-layersは60/90/105/120°を検査する。continuous-musclesで骨付着・停止部の追従と実メッシュのホバーを検査する。

これはソース形状を保つ表示用変形であり、張力・接触力の物理解析ではない。表面順序の確認は計測した自由部分での結果で、全三角形の衝突解決を主張しない。全筋の既知の半腱様筋方向変化条件は今回の範囲外として保持する。

0→120°での長頭経路長は535.4→514.2mm。測定した各段階で短縮。120°の自由経路余長比は1.0757、最大方向変化は21.56°。測定5肢位の表面逆転は0。付着/ホバーの回帰検証と単体41件・構文チェックは成功。

最終結果：continuous-muscles、short-head、terminal-muscle-layersの3件成功。terminal-muscle-layersの60/90/105/120°の全筋表示でも、薄筋の既存浅深条件と長頭/短頭の浅深条件を満たした。

後続の停止側の折り返し・時間連続性修正は[BICEPS_DISTAL_CONTINUITY](BICEPS_DISTAL_CONTINUITY.md)を参照。
