# 脛骨上での半月板本体の移動

> 後続修正: 高さ一定の移動では支持面から外れるため、現在は脛骨曲面の高さを取り直す方式へ変更。縁では移動量を制限する。[曲面追従と膝蓋骨](SURFACE_TRACKING_REVIEW.md) が現状。以下の移動量・高さ保持は前段階の記録。

2026-10-30。ユーザーが現段階の骨軌道を受け入れたため、停止していた半月板の相対運動を実装した。骨軌道・関節軸・Screw-homeの処理は変更しない。

## 現在の動き

半月板は下腿の子として骨の三次元運動を受けつつ、その本体を脛骨座標の後方へ移す。屈曲で後方移動、伸展で同じ経路を前方へ戻る。前後の根の推定点を保持し、根周囲から本体へ移動量を滑らかに増やす。全体を剛体として並進すると根が外れるため、その方式にはしていない。

以前の大腿骨支持点の近似による補正を再有効化したものではない。骨の不適合を半月板の変形で補う経路を削除し、屈曲角に連動する独立した脛骨上の移動とした。骨を動かす処理への逆作用はない。

添付図の内側6mm／外側12mmを本体の最大移動量の暫定目安とする。現在の0〜120°にsmoothstepで割り当て、便宜的に120°で最大とした。**図が120°で測定した値だと解釈したものではない。** 被験者固有の実測曲線でもない。根付近では移動量が減るので、半月板全体の重心移動量は6mm／12mmより小さい。

移動は脛骨座標で前後方向だけとし、各頂点の元の高さ・内外側位置を保つ。厚さの圧縮や未検証の上下変形は加えない。脛骨の支持面は局所平面近似で、傾斜した軟骨面に沿う厳密な接触拘束ではない。

根から20mmの距離で移動量を滑らかに増す。最大12mmに対し重み勾配の上限を制限し、以前の急な変形のような折り返しを避ける。元のジオメトリは保持し、複製のみを更新。Anatomyでは元頂点へ戻る。

Auto/Pause、手動角度、Mode切替の補間で使う**描画中の屈曲角**に連動する。目標角だけで半月板が先に飛ぶ挙動は作らない。表示のON/Fade/OFF・3Dフロートとの同期は従来どおり。新しいUIや独立モードは追加しない。

## 検証

実GLBで0/10/20/60/90/120/90/0°を往復。世界座標の頂点を下腿の回転・並進から逆変換して脛骨座標へ戻し、次を照合する。

- 前後の推定根が脛骨に対して保たれる。
- 本体に後方の相対移動が生じ、単なる脛骨固定ではない。
- 内外側位置・高さを保ち、外側の実際の重心移動が内側より大きい。
- 移動上限、Autoでの連動、Anatomyでの元頂点復帰。
- 既存の骨軌道・軸の骨内通過、Mode・Focus・カメラ・表示操作の回帰。

数値はmeniscal-excursion-review.json、画面はscreenshots/meniscal-excursionに保存する。根は粗いメッシュからの推定であり、軟骨接触・根の付着面・半月板応力を検証FIXしたものではない。

最終確認: 構文PASS、ロジック18/18 PASS、実GLB Edge UI 12/12 PASS。120°で本体の最大設定量は内側6mm／外側12mm、実メッシュ重心の相対移動は約4.14mm／8.47mm。これらは今回の描画結果であり、実測生体値の主張ではない。骨軌道・瞬間軸のモジュールはこの変更で編集していない。
