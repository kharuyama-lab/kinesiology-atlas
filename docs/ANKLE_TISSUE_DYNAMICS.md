# Ankle — 筋腹全長の変形・支帯・組織の層構造

後続のUI・操作速度の修正は [ANKLE_UI_PERFORMANCE.md](ANKLE_UI_PERFORMANCE.md) を参照。以下は接触計算の生成手法を説明し、通常の再生時には事前計算した形状を使用する。

2026-11-17。ローカル `feat/ankle-phase1` のレビュー用更新。関節軸・可動範囲・足趾の剛体的な扱いは変更しない。公開版は更新しない。

## 今回の問題と変更

以前の変形は足関節に近い端だけに集中し、筋腹の大部分が動かなかった。さらに、再構成した靭帯の一部が筋腱より外へ膨らみ、単に骨との衝突を除くだけでは組織どうしの交差が残った。後距腓靭帯は骨の内外判定の切り替わりで経路が跳ねた。

### 筋腹と腱を分けた長軸方向の変形

元GLBのprimitiveが持つ `Tendon` 材質名を表示材質へ差し替える前に保存し、筋腹と腱・腱膜を区別する。13の下腿筋は `MuscleExcursion` で元形状の長軸中心経路を作り、全長に変位を配分する。

- 元の筋の走行に沿って物質点を再配置する。新しい左右への迂回経路を作らない。
- 前・後脛骨筋、腓骨筋、長趾・長母趾筋はモデル上の腱経路長の変化から筋腹側の長さ変化を求める。元形状の腱周囲をガイドとして、足関節付近の腱が滑走する。
- 下腿三頭筋は長さを保持した自由アキレス腱の上端移動を受け、筋腹全体が短縮・伸張する。従来の「上方0.36 mまで固定し、下側だけを変形」は、実モデルの筋腹には使用しない。
- 起始側の端と、脛骨・腓骨の元の付着に近い筋腹の点は対応骨に残す。外側の筋腹は動き、骨との起始を滑り落ちさせない。近接1.3 mmの判定は粗い元モデルへの模式的な設定で、解剖学的footprintの計測ではない。
- 変位は筋腹長の18%以内へ制限する。これは表示の安定化設定であり、正常筋の実測収縮率ではない。
- 筋腹・腱膜の境界で変位を連続させる。独立名の長趾伸筋腱も長趾伸筋と同じ変位モデルへ接続する。足部の内在筋に能動収縮や足趾運動を追加しない。
- 自由アキレス腱の剛体的な長さ・幅の保持は継続する。他の腱については元経路上の模式的な滑走であり、全線維のひずみ保存を解くものではない。

これは筋活動・力・羽状角・腱ひずみを求める力学解析ではない。姿勢による幾何学的な長さ変化の表示であり、EMGによる活動の判定には用いない。

### 部位ごとの層関係

`config/ankle-tissue-layers.js` に、実際に交差する筋腱と深い靭帯の対応を明示する。すべての筋をすべての靭帯より表層へ押し出すことはしない。

- 長・短腓骨筋腱は踵腓靭帯などの表層を通す。
- 前方・内側・後方・足底の交差はそれぞれの組織の外向きに沿って検査する。
- 長腓骨筋腱は長足底靭帯の下のトンネルを通るため、この組み合わせを逆転させない。母趾内転筋・骨間筋などの深層も一律の表層化の対象にしない。足底方形筋と長足底靭帯の起始での連続は交差と区別する。
- 三角形面の方向が不安定に反転しないよう、解剖学的な外向きへ投射して実際の靭帯面との交差と間隔を求める。頂点だけでなく三角形重心も検査し、骨との接触と交互に調整する。
- 前距踵・踵舟・踵立方・距舟・長足底・足底踵立方靭帯は、中間部の過大な外方アーチを骨表面に近い経路へ修正した。足底筋を無理に外へ押し出す突起も抑える。端部の骨ローカル座標を保ち、新たな中間固定点は作らない。骨を貫く面は局所的に回避する。中間位では接触経路の履歴を解除して同じ形へ戻す。

描画順の強制や深度判定の無効化ではなく、表示メッシュ自体の位置関係を調整する。Fadeでは深層が透けて見えるため、ONでも層の重なりを確認する。連続的な全三角形交差の数学的保証ではなく、頂点・面重心と局所的な表面投射に基づく検査である。

### 支帯5構造

固定済み `muscular.glb` にある、上・下伸筋支帯、屈筋支帯、上・下腓骨筋支帯を追加する。名称は元GLBの実ノード名を使い、組織種別は筋ではなく結合組織とする。

元の面構成を保持して、対応する下腿骨・足部骨の動きへ追従させる。骨に近い元の端部を保ち、支帯の自由部分が対応する筋腱の表面を覆うよう調整する。非表示の腱も支帯表示に必要な場合は更新する。支帯の力や張力、腱を押さえる力学的な拘束は計算しない。上腓骨筋支帯には筋間中隔・腱鞘との連続もあり、骨への重み付けだけでは全付着を再現しない。

UIは後続修正で分離した。筋・腱は初期ON。靭帯と支帯はそれぞれ初期Fade（不透明度0.3）で、支帯はAxesと同じ列で独立切替する。作用筋群の4ボタンは個別リストの開閉にかかわらず表示する。

### 後距腓靭帯の連続性

- 粗い骨メッシュに対する1方向のレイ判定の切り替わりが、大きな逃げ経路への跳ねを生んでいた。後距腓靭帯に限り5方向の多数決で骨の内外を判定する。既存Hip/Kneeの判定は変更しない。
- 後上方の同じ側で経路を継続し、同程度に有効な別の方向へ突然乗り換えない。
- 前の自由部分を現在の骨運動で運んでから、経路補正だけを時間補間する。骨への両端の付着は補間しない。
- 自由部分の経路補正は15 mm/sを上限とする。必要な骨の回避は同時に保つ。
- 240フレームの底背屈追跡で、骨運動を差し引いた経路変化の最大値は0.75 mm/フレーム、端部の追従誤差は検査座標上0だった。以前の検査では約9 mmの跳ねがあった。
