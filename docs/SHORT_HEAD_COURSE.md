# 大腿二頭筋短頭のみの走行修正

長頭と他の筋、およびUIは変更しない。

従来は短頭にも長頭と同じ自由経路を使い、さらに長頭のX方向表面より内側へ押し込む補正を重ねていた。短頭の元の大腿骨沿いの走行を失い、局所的な膨らみと折れが生じていた。

短頭だけ元メッシュの大腿骨沿いの中心経路を基準にする。腓骨側への変位は全長に滑らかに分配し、遠位側の方向変化は自由部分の後半60%へ分配する。断面形状、起始側の端点、腓骨追従領域を保持する。左右方向へ短頭を押す補正は除去した。Anatomyの原形は変更しない。

## 検証と限界

short-head.spec.jsは0/30/60/90/120°で自由経路の余長比<1.15、局所方向変化<25°、腓骨付着誤差<0.1mm、終末屈曲での全長短縮を検査する。長頭は保存済み60/90/120°基準と比較する。continuous-musclesは実メッシュの付着と屈曲後ホバーを検査する。

既存の全筋検証は全て成功したとは扱わない。whole-muscle-shorteningは半腱様筋の方向変化条件で失敗し、terminal-muscle-layersのX方向完全分離条件も未解決。これらの閾値・判定を緩めたりスキップしていない。短頭を単に隠したり、骨や他筋の表示順序を変えて深部を装う処理はない。完全な筋間接触・筋骨接触の計算ではなく、確認用の走行改善である。

参考：短頭の大腿骨粗線からの起始と、長頭・外側広筋の間の位置は [Sonographic landmarks in hamstring muscles](https://pmc.ncbi.nlm.nih.gov/articles/PMC6776567/) を参照。

最終結果：構文チェック・単体41件・short-head・continuous-muscles成功。120°の自由経路余長比は従来1.2971から1.1156、最大方向変化は従来36.32°から24.61°へ改善した。長頭の保存済み基準は同一軸設定・描画収束後の検証で一致。詳細はshort-head-audit.json。
