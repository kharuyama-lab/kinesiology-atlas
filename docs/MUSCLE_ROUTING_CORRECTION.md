# 筋走行の修正・筋作用グループ — 2026-11-02

前回の「Hip復元」は、操作と端点の確認に偏り、筋腹の走行・腸脛靭帯の連動まで引き継げていませんでした。この記録は `SHARED_MUSCLES_AND_HIP.md` の初回実装に対する修正です。

## 修正内容

- 大腿筋のほぼ全長に股関節回転を分配する処理と、腓腹筋のほぼ全長に膝回転を分配する処理を撤去。大腿筋腹は大腿骨、下腿筋腹は脛骨に追従し、関節周囲の移行部で変形します。膝の並進とスクリューホームも同じ骨変換として反映します。
- 複数メッシュに分かれた筋の長軸比率は、部品ごとではなく名称で集約した全体から計算します。部品の境界で違う変形率が適用される問題を防ぎます。
- 既存Hip版から、骨表面距離比のsmoothstep、2回のトポロジー平滑化、大腰筋の上部固定域、腸脛靭帯の上部固定域、大腿筋膜張筋・大殿筋と腸脛靭帯の挿入部の変形場同期を移植。腸脛靭帯のFocus時の初期表示はFade。個別操作後の状態はMode切替で維持します。
- `Calcaneal tendon.r`（アキレス腱）の収録を実GLBで確認し、膝の関連組織へ追加。下腿と同じ骨変換で描画し、腓腹筋の下端で途切れないようにしました。筋ではなく腱であり、収縮エフェクトは与えません。
- 膝は屈曲・伸展・内旋・外旋の4筋群を1クリックでまとめて表示。屈曲群ではアキレス腱も表示します。股関節は既存Hipの6筋群（屈曲・伸展・外転・内転・外旋・内旋）を復元。グループ操作は肢位・カメラ・Modeを変更しません。
- 個別筋の表示は2列を維持。固定側の重複したSelection欄は表示せず、3Dフロートと個別リストの操作を使います。
