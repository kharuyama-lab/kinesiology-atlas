# Anatomy v0.2 / seamless mode foundation

## 共有状態

単一のScene、PerspectiveCamera、OrbitControls、rendererを保持します。Modeは `anatomy / kinesiology`、Focusは `body / hip / knee`。ModeをFocus名として扱いません。旧Hipのiframe切替は共通UIから除外し、legacy/hipの参照コピーは変更していません。

`setMode` はMode表示と目標肢位だけを変更します。Focusや組織表示、カメラ方向・距離、選択、axisToggle、sidebarの開閉をリセットしません。Quaternion補間により同一メッシュを移動し、右膝の変位分だけカメラとtargetを平行移動します。ユーザーのpanオフセットも保持します。

`setFocus` は関節固有UI、関連組織、カメラ中心と距離を変更します。Whole Bodyは明示的なホーム操作で標準肢位・全身の組織表示へ戻します。Mode切替からは呼びません。

## 名称と表示

筋の識別色は `src/palette.js` に固定。共通筋はHip版と同じ色を使い、全28筋を個別色にしています。左パネルは日本語名・2列配置、日英名は3Dポップアップ内。表示名はON / Fade / OFFで、内部のFade不透明度は0.3です。

`src/anatomy.js` の39組織は実GLBの `extras.za_name` と完全一致。28筋、9靭帯、2半月板。広筋の名前には `muscle` が必要です。日本語骨名は辞書と指骨・肋骨・椎骨等のパターンで対応し、実GLBの277骨格構造すべての対応をテストしています。

関節Focusでは組織単位の `tissueStates` が左行・選択欄・フローティング操作の状態源です。関節Focusに骨の表示トグルは置きません。投影した左骨格の境界箱が、右骨格に重なり、かつ手前なら30%不透明にします。境界箱による保守的な推定で、ピクセル単位の遮蔽判定ではありません。

追補: Whole Bodyはユーザー指定により `bulkStates` の骨／靭帯・軟骨／筋肉の3一括操作だけを表示します。個別行は隠し、3Dフロートからの操作も一括に連動（Allを明示）。骨格GLB中の軟骨名を持つ構造も靭帯・軟骨グループに含めます。対象範囲は現在登録している構造です。OFFは表示だけの変更で、メッシュをシーンから削除しません。

Hip/Knee Focusでは全身骨格をONに戻し、当該関節に関連する組織だけを個別操作します。無関係な靭帯は行・3DともOFFで、描画処理でも関連性を確認します。Mode切替は一括状態を維持。Whole Bodyを押すホーム操作でのみ一括状態をONに初期化します。

子メッシュの自動生成nameは解剖学名として使わず、za_nameを持つ親を探します。複数プリミティブを含む筋の識別を壊さないためです。

元GLBを保存してクローンから表示モデルを構築します。手動再読込時も既存の回転済みメッシュを再校正せず、元の座標から再構築します。

## 校正境界

股・膝中心推定の係数はconfig/knee.jsに集約。骨形状からの暫定推定であり、未FIXです。回転軸は現在の局所X/Y/Zの試作。外側の符号は左右の大腿骨位置から決めます。

Mode 1は解剖学的肢位。Mode 2 Kneeの屈伸・内外旋は股90°/膝90°、内外反は股90°/膝30°が基準です。スクリューホーム、半月板の脛骨への追従、模式的な膝蓋骨移動は屈伸に従属し、独立モードはありません。下腿軸のみON/OFF可能です。

膝の姿勢計算は `src/joint-motion.js`。各運動の角度を別々に記憶し、Mode/運動種類の変更ではリセットしません。内外反の符号・観察肢位・上限は数学的にテストしています。中心・軸の検証資料は `docs/JOINT_MOTION_REVIEW.md`。

既存の模式運動を残した基盤で、正しい生体運動をFIXしたリリースではありません。筋はAnatomyの元形状に留まり、靭帯は剛体追従で伸縮せず、半月板は脛骨と剛体移動、膝蓋骨は小さな直線移動のみです。Hip FocusのMode 2は同一シーンで状態を保持しますが、旧Hipの完成済み運動操作を統合していません。

開発順序: Anatomy → 関節中心/軸検証FIX → カメラ最終FIX → 関節運動 → 靭帯動態。断面・二関節筋・CKCは保留。
