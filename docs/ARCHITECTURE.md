# Interactive 3D Kinesiology Atlas — アーキテクチャ v0.1

## 基本方針
- **既存Hipサイト（hip-kinesiology）は一切更新しない**。完成済みHip v1.0.1を`legacy/hip/index.html`にそのまま独立コピーとして保管する。
- Mode 1は全身の静止解剖（右側の筋を中心に表示）、Mode 2は関節ごとの運動学。初期実装は右膝。
- Mode 3（二関節筋）、Mode 1の横断面、CKC reverse actionは今後の開発。未完成機能を選択できるように装わない。
- 3Dデータは Z-Anatomy 系の同一座標GLBを外部から取得。内部識別には glTF の `extras.za_name`を利用。
- 関節中心／運動軸は `config/knee.js` で一元管理。実測・目視検証後のFIXを前提とし、**v0.1は未校正**。教員への確認なしに解剖学的に正しい数値として扱わない。
- UIのスライダー／方向ラベルを運動学的な符号規約で統一：右下腿外旋＋、内旋−、外反＋、内反−。腰椎等を含む左右の参照系の固定は今後共通座標仕様に文書化する。

## v0.1のコード
- `index.html`：共通シェル、Mode 1/2 切替、骨・筋・靭帯の設定、組織ポップアップ。
- `src/main.js`：GLB取得、za_name登録、静止モデル、膝の運動ピボット、UI。
- `src/kinematics.js`：検証可能な純粋な角度変換・定性的靭帯表現。
- `config/knee.js`：ROM・初期肢位・主な対象構造の正確な名称と試作パラメータ。
- `legacy/hip/index.html`：完成済みHipの完全に独立したコピー。アトラスのHipボタンからiframe表示。

## 膝骨運動について
- 大腿骨と脛骨の相対運動を局所ピボットに分離する。90°股関節屈曲位を基本とする。
- 膝屈伸では自動的に終末伸展の下腿外旋を数度加えるが、これは **教育的模式値**。数値と運動軌跡は現時点で解剖学的に未検証。
- 内外反は30°膝屈曲位で±3°だけのストレスデモ（病的弛緩や実際の関節裂隙開大量を示すものではない）。
- 靭帯・半月板・膝蓋骨の静止メッシュはZ-Anatomyから表示可能。動態に伴う靭帯の解剖学的変形と、膝蓋大腿関節の真の追従軌道はv0.2以降の検証対象。パネルの「強調」は定性的な講義説明であって3Dモデルのひずみ計算ではない。

## 注意と研究倫理
- 学生配布・論文・公開時には、Z-Anatomy / BodyParts3D / nqwrc/3d-anatomy 由来の著作権表示とライセンス条件を保持すること。
- このv0.1ではGLBは同梱せず公開アトラスからロードする。教材自体の初回読み込みにはインターネットが必要。外部供給元の仕様変更によるエラーには注意。
- 原講義スライドp.40の内外反→MCL/LCL対応はp.16と逆であるため、**外反→MCL、内反→LCL**で実装する。
