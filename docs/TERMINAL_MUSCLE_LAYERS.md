# 最終屈曲域の浅深と直線化

2026-11-02。bbace9aに対する追加修正。大腿二頭筋長頭の受け入れ済み経路は維持する。

## 変更

- 半腱様筋・半膜様筋の外方への全長補正を最大4mmに抑え、浅層筋を押し退ける方向への過剰なせり出しを減らした。
- 内側4筋は80〜120°で経路の曲がりと元経路から残す偏位を連続的に減らす。起始・停止側の保持領域は変更せず、自由部分全体の経路を直線へ近づける。
- 薄筋は半腱様筋だけでなく半膜様筋の表面も参照する。中心線の順位ではなく、実メッシュから得た表面の交差量に基づく。
- 大腿二頭筋短頭は長頭表面の深側に経路を確保。長頭の経路や材質・表示順序には補正を加えない。
- 浅深補正は単独頂点を押し出す方式ではなく、必要量を滑らかな包絡関数で広い長軸区間へ配分し、断面全体を移動する。付着部近傍は対象外。
- Anatomyの静止原形、四頭筋・腓腹筋・靭帯の経路式、Hip、UIの並びは今回変更しない。

## 確認

全筋ONの60/90/105/120°で、実際に描画する筋表面を計測した。薄筋／半腱様筋、薄筋／半膜様筋、短頭／長頭の3組を比較。自由部分の表面点からY-Z平面上3mm以内にある相手表面のX方向位置を照合し、測定領域での逆転がないことを確認するテストを追加した。対象は起始・停止の付着領域を除く筋部分であり、三角形同士の完全な接触判定ではない。

120°での自由経路長／両端距離（1に近いほど直線）：

| 筋 | bbace9a | 今回 |
|---|---:|---:|
| 半腱様筋 | 1.0759 | 1.0278 |
| 半膜様筋 | 1.0859 | 1.0377 |
| 縫工筋 | 1.0854 | 1.0469 |
| 薄筋 | 1.0865 | 1.0629 |

長頭は60/90/120°の経路長と上記比率を受け入れ済み記録と比較する回帰条件を追加。差の許容は1e-6。120°の内側・外側画像を目視確認した。

## 残る制限

以前からの `whole-muscle-shortening` は依然として失敗する。今回、短頭の表層突出を避ける経路は確保したが、深部での経路長・曲がりは同テストの条件を満たしていない。生理学的な短縮量や完全な筋同士・筋骨接触の解決は主張しない。失敗条件は緩和・スキップせず保持し、PRは下書きのままとする。

検証結果：構文チェック・単体41件成功。terminal-muscle-layers、continuous-muscles、shared-muscles成功。whole-muscle-shorteningの既知失敗は短頭の自由経路比率等で継続し、条件は変更していない。

最終のbone-muscle-routesも成功。今回の関連UI成功は4件で、浅深・長頭維持・直線化、筋ホバー、モード共有、骨に対する追従を確認した。
