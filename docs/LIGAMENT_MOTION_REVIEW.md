# 膝靭帯の追従基盤（2026-11-02）

## 問題と変更

従来、膝靭帯は一体の静的メッシュとして大腿骨側へ取り付けられ、筋用の追従処理からも除外されていた。脛骨・腓骨の回転と並進が靭帯の遠位付着部へ伝わらなかった。

ACL、PCL、MCL浅層・深層、LCLの5メッシュに、元メッシュの近位・遠位端を使う付着カラーを設定。近位側は大腿骨、遠位側はACL/PCL/MCLで脛骨、LCLで腓骨に固定する。両端は各骨の完全な回転・並進へ追従。中間部は断面の向きを補間して変形し、単純な頂点の線形混合による断面の潰れを避ける。各フレームは元頂点から計算し、累積誤差を防ぐ。

骨運動・Screw-home・半月板・膝蓋骨・軸の式は変更していない。表示のON/Fade/OFF、浮動UI、Mode間の表示状態保持は既存操作を使う。新しい操作ボタンは追加しない。

## 確認画面

ローカルの ?review=ligaments&axis=condyle で筋を隠し、5靭帯と半月板を初期表示する。既存の2列の靭帯リストだけを表示し、AutoとReset pose、Axes、膝蓋骨の配置は維持。従来の ?review=knee は骨・半月板の確認用として維持。

## 実装の範囲

付着位置は元GLB端領域からの暫定推定。組織学的な付着面や束の区分を検証FIXしたものではない。中間部の骨面への巻き付き・接触解法、ACL/PCLの機能束別の応力、無負荷長や剛性による張力・ひずみ計算は未実装。診断用spanRatioは端領域中心間の幾何学的距離比であり、生体のひずみ・緊張度ではない。角度だけの一律な伸長・色変化は追加しない。

## 参考一次資料

[Marieswaran et al., 2018, An extended OpenSim knee model for analysis of strains of connective tissues](https://link.springer.com/article/10.1186/s12938-018-0474-8) は付着点・複数束・材料設定を持つモデルとして参照。今回のZ-Anatomyメッシュにその座標・材料係数やひずみ値を直接転用していない。

## 検証

合成形状：骨の回転と並進、非表示中の更新、元メッシュ非破壊、原姿勢への復帰。

実GLB：5靭帯×屈曲0/20/60/90/120°、内外旋−15/0/30°、内外反−3/0/3°の両端頂点を、対応骨の剛体変換による期待位置と照合。LCLの遠位骨が腓骨であること、全頂点が有限、表示循環・Mode保持、1280×800でスクロール超過0pxを検証する。0/30/90/120°の内外側ビューを画像保存。骨面非貫通や生理的緊張度の妥当性を承認するテストではない。

結果：構文PASS、ロジック21/21 PASS。UI全17ケースのうち16件PASS、半月板のフォーカス直後の未更新フレームを読んだ1件は描画後に測るようテストを修正し、単独再実行PASS。旧Axesチェックボックス操作も現在の表示ボタンへ更新。
