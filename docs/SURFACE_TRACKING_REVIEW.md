# 半月板の脛骨曲面追従と膝蓋骨の滑車部追従

2026-10-30。ユーザー添付で、半月板の高さ一定の後方移動では支持面から外れること、膝蓋骨が屈曲しても高い位置に残ることを確認。移動量のみの検証を改め、面との位置関係を検証する。既存の大腿骨・脛骨の軌道とScrew-homeは変更しない。

## 半月板

脛骨を構成する**全メッシュ**の近位三角形から上方支持面を抽出する。粗い面境界による跳躍を避けるため、1.5mm格子と小さな平滑化で連続した高さ場を作る。厳密な軟骨面そのものではなく、骨メッシュ由来の支持面近似。

各頂点について、伸展位の支持面からの高さ差を保存する。後方へ移動した先で支持面高さを取り直し、その差を保って頂点の高さを更新する。前後の推定根は動かさず、周囲から本体へ移動量を増す。元の厚みを押し潰す圧縮は加えない。

目標6mm／12mmは最大の要求量とし、脛骨の縁から外れる場合には、要求距離より支持面上に留まることを優先して移動量を抑える。元からの張り出しに0.5mmの許容を加えた範囲で止める。したがって、現モデルの重心移動量は前版の数値とは異なる。

これは「元の高さを保つ」から「元の支持面に対する高さ差を保つ」への変更。以前の大腿骨支持点による半月板補正は使用していない。

## 膝蓋骨

少量の直線移動を廃止し、実際の大腿骨前面の両側の面へrayを当てて滑車部の経路を作る。授業資料のように、屈曲とともに前面から遠位へ回り込ませる。後方の顆間窩へ単純に押し込む経路にはしない。

膝蓋骨の屈曲を膝屈曲の2/3として暫定設定し、後面の全候補頂点と大腿骨面の関係から並進を調整する。中心部だけでは周辺がめり込むことがあったため、後面の周辺頂点も含めた。1mmのray方向のクリアランスは数値上の目標であり、実測軟骨厚ではない。

初期の伸展位は厳密に維持し、20°までに滑車部の支持経路へ滑らかに移る。経路は2°刻みで計算し、その間を補間する。中心の経路を決める終端角105°等は、0〜120°の現メッシュ確認用の仮定としてconfig/patella.jsへ分離した。膝蓋腱の長さ・筋力・軟骨接触圧から解いた運動ではなく、正確なtilt/spin・内外側追跡は未FIX。

2/3という向きの比は [Hamaiらの一次研究](https://pubmed.ncbi.nlm.nih.gov/23778643/) を参考にした。同研究は荷重下の動的深屈曲であり、その位置データを現表示の開放運動連鎖へそのまま転用していない。モデル固有の並進はメッシュ表面から計算する。文献を参照していることを、本メッシュの適合性保証とはしない。

## 同期と検証

両者とも目標角でなく描画中の屈曲角から毎フレーム求める。Auto・手動操作・Mode補間で同じ経路を往復し、Anatomyでは元座標・向きへ戻る。UI・独立トグル・運動モードは追加しない。

実GLBで0/20/30/45/60/75/90/120/90/0°を確認。半月板の頂点を脛骨座標へ逆変換し、支持面からの高さ差と、元の高さ一定の負の対照を比較する。後者では面とのずれが生じることを確認する。

膝蓋骨は0/30/60/90/120°で実際の全メッシュ頂点を大腿骨座標へ戻し、モデル内部のgap計算とは別に、三角形への最近点距離と7方向rayによる骨内判定を行う。確認角度の頂点めり込み数0、最近頂点距離は伸展約2.26mm、30〜120°で約0.85〜0.92mm。これは離散頂点の検査で、全三角形同士の非交差や軟骨接触を保証しない。

画像・数値はscreenshots/surface-trackingとsurface-tracking-review.jsonに保存。根の位置、支持面抽出、膝蓋骨の経路・向き・軟骨適合性は解剖学的レビューを継続する。

構文PASS、ロジック20/20 PASS、実GLB UI 13/13 PASS。膝蓋骨後面の周辺部を加えた最終変更後は、通常画面・比較画面・曲面追従の3テストも再実行してPASS。支持面の検証は意図した高さ場に対する一致であり、生体の軟骨面精度の数値ではない。
