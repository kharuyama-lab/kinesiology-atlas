# 元の筋走行・四頭筋の追従先・角度欄の修正

## 修正の根拠

前回の両端から作る3次曲線と断面の回転・太さ補正は、元モデルの走行を平坦化し、筋腹と腱部の形を変えていました。中心線が逆行しないという検査を、筋走行の正しさの代わりに使ったことも不十分でした。この制約と人工的な太さ補正は撤回しました。

実GLBでは大腿直筋・広筋が複数のメッシュを含み、筋腹の下端と、腱部を含む全体の下端が異なります。例として大腿直筋の一方のメッシュの下端Yは0.4872、もう一方は0.3705、静止時の膝蓋骨中心Yは0.4443です（モデル座標）。全体の下端を膝蓋骨フレームへ結び付けた以前の処理は不適切でした。

## 最終変更

- 元の筋表面全体を基準にして骨移動の変位を配分。端点間の新しい直線・単純な曲線へ断面を並べ替えません。断面の人工的な縮小・拡大を廃止。
- 大腿直筋・広筋は、大腿骨上の元の中間走行を保持し、膝蓋骨側の経由点と脛骨側の末端へ連動。元GLB内の腱部も同じ参照経路で追従します。
- 縫工筋は元の斜走・湾曲を大腿骨側の参照として保持し、膝周辺で断面がつぶれないよう向きを連続調整。ハムストリングス・腓腹筋は元の表面を全長で変位させます。
- Anatomyで元座標へ戻すこと、筋群操作、識別色、ON/Fade/OFF、ホバーは維持。
- 角度欄の現在値と端点ラベルから英語を削除。中央欄を116px固定・数値を右揃え・等幅数字にし、左右のラベルも固定グリッドへ配置。

## 検証範囲

- ロジック31件：元の湾曲成分と断面寸法の保持、大腿骨側の元走行、膝蓋骨経由点と脛骨側末端を検査。
- 実GLBの膝0/30/60/90/120°で、追従先・断面の反転/極端なつぶれ・全16筋/腱の実表面ホバーを検査。形状の検査は中心線の非逆行だけに依存しません。
- 大腿直筋・縫工筋は骨を表示した単独像で目視確認：`screenshots/continuous-muscles/Rectus-bone-course.png`、`Sartorius-bone-course.png`。
- 角度0/9/10/99/100/120°と内外旋−15/−1/0/1/9/10/30°で、現在値・左右ラベル・スライダー・描画領域の座標と幅/高さが変化しないことを検査。角度欄に英字がないことも確認。
- 最新UI回帰結果を追記します。

骨との接触・巻き付きの物理計算、全付着面の検証、筋力計算を完了したという意味ではありません。元の走行を失わないことと、誤っていた追従先・表示の揺れを修正した記録です。既存Hipのリポジトリ・公開サイトは変更していません。
