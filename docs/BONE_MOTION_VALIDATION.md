# 右膝の関節運動検証 — 現状は未承認

検証順序を **関節 → 靭帯・半月板 → 筋肉** とします。本工程では筋・靭帯の追加実装を行いません。操作テストの通過を、解剖学的妥当性の合格とは扱いません。

## 観察用の入口と自動往復

ローカル確認: `http://127.0.0.1:8080/?review=knee`

右Knee・Mode 2・右外側視点・下腿軸ONで開始し、筋・靭帯・半月板はOFF、対応する操作欄も隠します。一般のAtlas画面の初期表示は変更しません。骨格は全身両側を保持します。

3D画面のAutoで現在角度から往復、Pauseでその角度に停止。手動入力・運動種類変更・Reset poseは停止します。Anatomyへ切り替えた間は進行を停止し、戻ると同じ角度・再生状態から再開。Whole Bodyはホームとして停止・リセットします。

屈伸42°/sは旧Hip版の送り速度を引き継ぎ、内外旋15°/s・内外反1.5°/sとしました。表示上の観察速度で、生理的な運動速度を規定しません。自動往復中の膝姿勢は指令角に直接合わせ、補間による角度表示と姿勢の遅れを避けています。

## 修正した観察上の不具合

高解像度画面でrendererの描画バッファだけを拡大し、canvasのCSSサイズを指定していなかったため、実プレビューではcanvasがホストの約1.6倍に表示されていました。投影上の中心は合っていても、見える膝は画面下にずれていました。

canvasのCSS幅・高さをホストに一致させることで修正。実プレビューでホスト/Canvasとも約461.82×1021.57 CSS pxとなり、描画バッファは739×1635のまま、高解像度を保持しています。倍率2・462×1118のブラウザーテストを追加し、CSS寸法一致と右膝中心の投影位置を確認しました。

## 骨表面サンプルによる基礎監査

大腿骨遠位20%から419点、脛骨近位20%から525点を取り、屈曲ごとに最も近い頂点サンプル間の距離を測りました。股の共通回転は距離を変えないため省略し、膝の回転だけを評価しています。詳細は [生データ](knee-surface-audit.json)。

## 妥当性の判定

| 項目 | 現状 |
|---|---|
| 入力方向・符号・角度範囲・基準肢位 | 数学的/操作上の検査を通過 |
| 往復・停止・反転・モード間保持 | 操作検査を通過 |
| 右膝が描画領域中央にあること | 標準倍率/高解像度で確認 |
| 膝中心・屈伸軸・長軸回旋軸の解剖学的妥当性 | **未FIX** |
| 屈伸に伴う転がり・滑り・接触点移動 | **未実装**。現状は固定ピボット回転 |
| 骨の穿通・全表面の接触判定 | **未検証**。今回の距離サンプルでは判定不能 |
| 内外旋・内外反での関節面の追従 | **未承認** |

したがって、現状の骨運動を教材として使用可能と判定していません。まず屈伸の中心・軸と関節面の軌道を合わせ、その基盤を確認してから内外旋/内外反を詰めます。靭帯・半月板、筋の精密化はその後です。既存の中心候補比較は [中心・軸資料](JOINT_MOTION_REVIEW.md) を参照してください。
