# 接触点を中心とする半月板支持部とPatella表示

2026-10-30。ユーザーの追加定義「前後の固定点を保持し、内外側顆との接点を半月板の中心部とする」を採用。既存の大腿骨・脛骨軌道と膝蓋骨追跡は変更しない。

## 共通の拘束

現骨軌道モデルが推定する内側・外側の接触点を、骨の完全な回転・並進から脛骨座標へ変換する。屈伸・内外旋・内外反の全てで同じ計算を使用し、角度ごとの別の半月板アニメーションを足さない。

接触点周囲の半月板本体を「荷重支持部」と定義。その範囲の重み付き中心を、脛骨支持面内で接触点へ合わせる。C/O形全体の体積重心を接触点に置く意味ではない。上下位置は既存の支持曲面と本体の厚みで扱うため、三次元空間の接触点と体積中心を同じ高さに置かない。

支持範囲は7mmの滑らかな重みで選び、接触が移ると材料上の支持範囲も移る。同じ材料の一点を全運動域で引き回す方式にはしない。前後の推定根は移動量0とし、20mmの範囲で本体へ変形量を増す。中心を合わせるのに必要な並進量を、その根拘束の影響を考慮して計算する。

13mmの変形上限と脛骨縁の制限は保持。拘束が両立しない場合は中心残差が残り、接触点の表示だけを移して一致したことにはしない。実際に変形した頂点から支持部中心を再計算して検証する。Anatomyでは接触拘束を解除して元ジオメトリへ戻り、Modeの移行中は拘束を滑らかに適用する。

従来の「屈曲角に6mm／12mmを割り当てる」駆動は廃止した。現在の移動量は骨モデルの接触点に依存する。

## 回旋と内外反の表現

内外旋では接触点の前後・内外側移動に荷重支持部が追従する。内側・外側で前後方向が異なる動きを持つ。支持面からの高さ差を保持し、前後の根は残す。

同じ屈曲角・同じScrew-homeで、回旋・内外反だけを0にした基準と比較する。接触点と脛骨支持面の間隔が減った側では、支持面より上にある部分の高さを抑える。内反で内側、外反で外側の縮小が増えることを確認。回旋でも、接触位置が変わって間隔が減る部位には同じ規則を適用する。

縮小係数は最大0.20の暫定値。根の固定点と底面の支持を保ち、開いた側を任意に膨らませない。これは**描画上の高さ縮小**であり、実測圧迫量・材料ひずみ・接触圧・荷重の推定ではない。荷重条件・軟骨・靭帯・組織物性・体積保存を解いていない。周辺への押出量も定量再現とは扱わない。

回旋の設計参照は [Fuchsらの荷重MRI研究](https://pubmed.ncbi.nlm.nih.gov/36192527/)、内外反の参照は [BendakらのMRI研究](https://pubmed.ncbi.nlm.nih.gov/40809996/)。いずれも荷重下での研究で、移動は個体形状・荷重条件に依存する。文献の変位量を角度へ直接換算していない。

## Patellaの表示

Kneeの左パネルに「膝蓋骨」1クリック循環を追加。ON → Fade → OFF → ON。Fadeは不透明度0.3で、数値をUIへ併記しない。3Dクリックのフロートにも同じ表示操作を置き、左と同期する。OFFからは左のボタンで戻せる。

状態はMode切替で保持。非表示でも追跡計算とシーン内の構造は保持し、再表示すると現在角度の位置へ戻る。全身の骨一括操作は全身表示内の状態とし、関節用の個別Patella設定を意図せず変更しない。Whole BodyホームはPatellaもONへ初期化する。他の骨格の常時保持は継続。

## 検証

屈曲0/30/90/120°、回旋−15/0/+30°、内外反−3/0/+3°で、実メッシュ頂点を脛骨座標へ戻し、支持部の中心残差、前後の根、曲面上の位置、閉じる側の実際の高さ減少を確認。支持中心の検証閾値は0.5mmであり、元の接触点推定の解剖学的精度を保証する値ではない。

表示は左・フロート両方の循環、Mode間保持、全身一括との連携を確認。小さい画面でのパネル超過も確認する。接触点・固定根・支持面・縮小係数は未FIXで、実際の負荷を受けた正常膝の再現と承認したものではない。

最終確認: 構文PASS、ロジック20/20 PASS、実GLB Edge UI 15/15 PASS。1280×800のKnee画面のパネル超過0px。記録はmeniscal-contact-centre-review.json、画像はscreenshots/meniscal-contact。検証点の中心残差が閾値を下回ることを、実際に変形した頂点から再計算して確認した。骨・膝蓋骨の軌道モジュールはこの変更で編集していない。
