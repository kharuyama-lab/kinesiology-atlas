# 2026-11-06 更新 — 追従の滑らかさ

ユーザー確認により形状と追従挙動を基準として保持し、カクつきの要因となる経路更新を調整した。

- 0.5 mmごとの経路探索の後に6回の二分探索を入れ、接触経路を約0.008 mm刻みまで連続的に精細化する。
- 初期の回避側を基準に前の接触高さの近傍から探索し、同程度の解があるたびに別方向へ切り替わることを避ける。
- 必要な迂回量が減る際は時間に応じた指数追従でしなやかに戻す。増やす際は骨へ入らない最小量を即時確保する。補間候補自体も骨内外判定を通す。
- 固定端は補間せず、対応骨へ直接追従させる。中間部にのみ経路調整を適用する。
- 骨姿勢が止まっても中間部の追従が完了するまで更新し、収束した部分は再計算しない。中間位では初期経路を再現する。

単体テストに、障害骨が離れた際に経路が一度に切り替わらず、単調に滑らかに戻り、両端固定と骨非貫通を維持する確認を追加した。骨運動・可動範囲・組織の追加・UI変更は行わない。

# 2026-11-06 更新 — 中間固定を廃止し、自由な帯の経路へ再構成

ユーザー画像で示された中間部の骨への貼り付き・埋没・細い引き伸ばしを受け、端部の接触誤差だけで合格としていた検証を撤回する。以前の「付着部カラー12%」と重みの端部飽和は、中間に相当する頂点も骨へ固定し得た。元メッシュを個々に押し出す試作でも過大な変形が生じたため採用しない。

## 現行の表現

元GLBの実名、対応骨、近接する付着位置、幅を基に、滑らかな帯を生成する。元GLBの共有ジオメトリは変更しない。原形状そのものの再表示ではなく、運動追従のためのsource-derived表示形状へ変更している。各帯は24区間、幅方向8区間。固定するのは最初と最後の端部行だけで、中間の固定点は0。

端部は対応する骨の実三角形表面上に固定し、骨ローカル座標として保持する。隣の骨の内部に隠れる面への付着を避ける。各線維をそれぞれの付着点と骨面の外向き法線に沿って曲線接続する。中間は両端の変換に応じて動き、骨のローカル座標に固定しない。

中間の経路は、骨の閉じた面に対するレイ交差の内外判定を用い、頂点と面の中心が骨内を通らない方向・小さい迂回量を選ぶ。骨とともに経路の基準方向も回す。世界座標に固定された迂回方向は使わない。数値検証の許容侵入深さは0.1 mm。これは完全な連続体衝突保証ではなく、表示メッシュのサンプルに対する判定である。

長足底靭帯は一枚の面で異なる停止骨を横断させず、立方骨と第2〜5中足骨へ向かう5つの表示束に分離する。各束の付着点は足底側の最外面へ投影する。これは束の教材用近似であり、細かな層構成や実測線維の再現ではない。

## 詳細アコーディオン

一括ON/Fade/OFFを見出し行に残し、その行を開くと従来の2列個別リストを表示する。Ankleでは初期状態を閉じる。筋と靭帯で同じ共通部品を使用し、Hip/Kneeは既存の展開状態を初期値として保持する。各Focusの開閉状態を記憶し、名称ホバーと3D選択も使用できる。筋肉のAnkle実装はまだ行わない。

## 検証の変更

端の接触に加え、中間固定点数、全中間頂点と面中心の骨内侵入、補正済み中間位への復元、詳細開閉と一括操作を合否条件とする。初期隙間のある脛距/脛腓靭帯に加え、両端間に障害骨を置いた独立したテストを追加し、端は固定したまま中間を外側に通せることを確認する。

現行の形状と走行はユーザーによる再確認対象。骨・軸FIXやHip/Kneeの運動モジュール、公開mainは変更しない。以下は過去の段階の記録であり、原メッシュの保持や中間点補正については本節を優先する。

# 2026-11-06 更新 — 一括UIと骨面付着固定

## 剥離の修正

以前の追従は元モデルの骨との隙間も保存していた。今回は対応骨の実三角形表面へ両端領域を投影し、その位置を実際の所有骨のローカル座標として保存する。腓骨側はFibula.rに固定する。長足底靭帯の複数の停止先も、最寄りとなった各骨に個別固定する。毎フレーム最寄り点を取り直して骨面上で滑らせる処理は行わない。

元形状は共有GLB上で保持するが、表示用の中間位形状は骨との隙間をなくすため補正する。補正変位をメッシュ隣接関係に沿って平滑に広げ、端部だけを局所的に折り曲げない。中間位へ戻した際は、この骨面に合わせた補正済み形状へ復元する。

これは解剖学的footprintの厳密な同定とは別の幾何学的接触拘束。元形状の誤差が大きい脛舟/長足底などでは補正量も大きいため、形状監査値を残す。骨運動・軸・筋肉・公開版は変更しない。

# Ankle Phase 2 — 靭帯追従の初版

2026-11-06 JST。骨・軸の教材用FIXはローカルコミット dbe9119、設定バージョン ankle-bone-fix-1。公開mainとremoteへの変更なし。

## 実装範囲

既存の固定joints.glbから16種類の右靭帯を使用。靭帯の実名、対応骨フレーム、収録状況はANKLE_LIGAMENT_SOURCE_AUDIT.jsonに記録。

- 遠位脛腓靭帯3種類。
- 内側3種類（後脛距、脛踵、脛舟）。原名以上の浅層/深層や束への分割はしない。
- 距骨下5種類（前/外側/内側/後/骨間距踵）。
- 足根部5種類（距舟、踵舟、踵立方、足底踵立方、長足底）。

既存の2列靭帯リスト、共通ON/Fade/OFF、一括表示と3Dホバー/選択を使用。Ankle専用の説明パネル・関節設定・View一覧は追加しない。筋・腱は追加しない。既存Hip/Kneeの運動・追従モジュールと軸のFIX設定は変更しない。

## 追従方法

原形状を複製し、元GLB共有ジオメトリを変更しない。二つの対応骨表面に対する距離差から両端の候補領域を抽出し、各12%を付着部カラーとして対応骨の剛体変換へ固定する。中間部は連続した重みと回転補間で断面を輸送する。特定の骨のY座標だけで全靭帯の両端を決めない。

この付着部カラーは原形状から求めた推定であり、剖検で検証したfootprintではない。元形状にある骨との隙間を自動で吸着補正しない。長足底靭帯は立方骨に加え第2〜5中足骨の表面を参照し、停止側は現在の共通前足部フレームで輸送する。

中間位での原座標復元、各カラーの骨相対固定、4運動全域の数値有限性を検証。spanRatioは原形状両端中心の距離比であり、靭帯ひずみ・張力ではない。色は組織群の区別に使用し、張力の数値や緊張エフェクトはまだ実装しない。

## 確認が必要な点

- 前距腓/踵腓/後距腓靭帯の対応ノードは、固定したskeletal/joints/muscularの全実名一覧にない。外側距踵靭帯を踵腓靭帯の代用品にしない。外側3本は別途形状・付着部の追加設計が必要。
- 脛舟靭帯の原形状と舟状骨の間に約9 mmの頂点サンプル距離がある。原モデルを保持し、付着部の同定を見直す。元GLBの表現を完全な三角靭帯の束構成と同一視しない。
- 前/内側距踵靭帯などの両端間距離比が運動端で大きく変化する。これは現在の骨連動・元形状・推定カラーの組み合わせによる監査値であり、生理的な伸長率として教材に出さない。
- 骨/靭帯間の動的衝突、骨面への巻き付き、非線形材料特性は未検証。実装完了・生体力学的妥当性の確認済みとは扱わない。

この段階ではまず原形状と追従をユーザーが確認する。外側3本の補完、付着部の調整、定性的な緊張表現はその確認結果に基づいて進める。Phase 3の筋・腱には進まない。
